# Hiii Shivann ❤️

A responsive, romantic website and personal digital love letter created for Shivann.

## ✨ Features
- **Original Visual Identity**: Faithful reproduction of typography, composition, colors, and layout.
- **Organic Flower Magic**: Interactive flower trail using the exact 13 flower assets, with smooth lifecycle animation (appear, float, fade-out).
- **Universal Responsiveness**: Fully responsive across mobile phones, tablets, laptops, and wide desktops without text clipping or layout overflow.
- **Dual-Device Interaction**:
  - **Desktop**: Cursor-based flower blossom trail.
  - **Mobile & Tablet**: Smooth touch + drag trail with distance tracking.
- **Accessibility**: Support for `prefers-reduced-motion`.
- **Fast & Modern**: Built with HTML, CSS, JavaScript, and Vite.

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
